# いさか鍼灸・美容整体院 LP

完全予約制の美容整体・鍼灸サロン「いさか鍼灸・美容整体院」のランディングページ（ホームページ兼用）。

- 単一HTML（CSS/JS/SVGすべて内包）
- 構成: 治療院LP 10の黄金構成準拠
- デザイン: ベージュ／木目調／柔らかい曲線
- デプロイ: Coolify (nginx:alpine / Dockerfile)

## 差し替えが必要な箇所
- 電話番号（`tel:` 含む）
- 公式LINEのURL
- 施術者ポートレート（現状SVGプレースホルダー → AI生成画像 or 実写へ）
- 担当歴の「◯年」
- 営業時間・定休日（仮: 10:00–20:00 / 水・日休）
